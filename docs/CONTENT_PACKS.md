# Sistema de Paquetes de Contenido

Todo el contenido de DAREVO estará organizado en Content Packs.

Un Content Pack es una colección de actividades agrupadas bajo una temática o modo de juego.

Ejemplos:

- Clásico
- Parejas
- Familia
- Fiesta
- Adultos
- Halloween
- Navidad
- Streaming
- Comunidad

Cada paquete podrá instalarse, actualizarse o desactivarse sin modificar el DAREVO Engine.
