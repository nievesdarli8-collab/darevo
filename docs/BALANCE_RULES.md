# Reglas de Balance

El DAREVO Engine deberá procurar:

- Alternar tipos de actividades.
- Evitar repeticiones consecutivas.
- Distribuir la participación entre todos los jugadores.
- Ajustar la intensidad de la partida.
- Evitar actividades incompatibles con la cantidad de jugadores.
- Respetar siempre las restricciones de consentimiento.

Estas reglas servirán como base para el futuro Director de Diversión (IA).
