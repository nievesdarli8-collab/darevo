# DAREVO - Modos de Juego

## Modo Clásico

Descripción:
Modo base de DAREVO.

Objetivo:
Disfrutar una partida equilibrada combinando preguntas, retos, minijuegos y eventos.

Cantidad de jugadores:
2 a 12.

Duración:
10, 20, 30 o ilimitada.

Tipos de actividades:

- Verdad
- Reto
- Minijuego
- Trivia
- Evento
- Castigo
- Desafío

Condición de victoria:

No existe un ganador obligatorio.

El objetivo principal es la diversión del grupo.

Este modo servirá como base para todos los demás modos del juego.
