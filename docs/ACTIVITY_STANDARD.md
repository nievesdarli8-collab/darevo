# Estándar Universal de Actividades

Toda actividad de DAREVO debe contener obligatoriamente:

- ID
- Título
- Descripción
- Tipo
- Jugadores mínimos
- Jugadores máximos
- Duración
- Intensidad (1–5)
- Consentimiento requerido

Ninguna actividad podrá incorporarse al juego si no cumple este estándar.

Este documento es obligatorio para todas las futuras expansiones.
