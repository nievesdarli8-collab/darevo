# Reglas del Contenido

Todo el contenido de DAREVO debe cumplir:

- Ser divertido.
- Ser fácil de entender.
- Poder jugarse en menos de un minuto.
- No depender de materiales externos salvo que se indique.
- Respetar el consentimiento.
- Tener instrucciones claras.
- Poder reutilizarse en distintos modos de juego.
