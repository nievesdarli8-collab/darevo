# Tipos de Actividades

Todas las actividades del juego pertenecen a una de estas categorías:

1. Verdad
2. Reto
3. Minijuego
4. Trivia
5. Evento
6. Castigo
7. Desafío
8. Ruleta

Cada actividad tendrá:

- ID
- Categoría
- Dificultad
- Duración estimada
- Cantidad mínima de jugadores
- Cantidad máxima de jugadores
- Nivel de intensidad
- Consentimiento requerido
